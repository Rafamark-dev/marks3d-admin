2. Manter os produtos da loja

Abra uma nova consulta no SQL Editor, copie o catálogo inicial e execute. São os dez produtos e preços da loja aprovada. Produtos com os mesmos IDs não são sobrescritos.

3. Cadastrar o acesso por nome e senha

O login do painel é por nome de usuário e senha. Ter o projeto Supabase pronto não cadastra automaticamente esse acesso. Você não precisa fornecer um e-mail pessoal.

O serviço de autenticação usa uma identificação interna, gerada a partir do nome. Ela não recebe mensagens e não aparece na tela de login da loja.

  1. Abra Authentication → Users → Add user → Create new user no Supabase.
  2. No campo Email dessa tela de configuração, cole a identificação interna acima. Defina a senha diretamente no campo Password e deixe Auto Confirm User ativado. Clique em Create user.
  3. Se essa identificação já existir, confira o cadastro existente. Não exclua nem altere o usuário do outro site.
  4. Copie a autorização pelo botão abaixo e execute em uma nova consulta no SQL Editor. Ela libera somente o usuário correspondente a esse nome.

4. Publicar na loja

Entre no painel, confira os produtos e teste o cadastro de uma peça não publicada. O conteúdo administrativo aparece somente após autenticar um usuário autorizado.

O catálogo conectado está ativo nesta versão. Para mostrar uma peça na loja, marque Publicar na loja e salve o cadastro. A alteração aparece quando a loja é aberta ou recarregada. Para retirar uma peça da vitrine, desative essa opção e salve. O cadastro será mantido no painel.
